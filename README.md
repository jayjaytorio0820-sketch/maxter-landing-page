# Maxter Riding Gear — Landing Page

Landing page for **Maxter**, a Philippine moto jersey brand (Series 01 — Marilaque).

## What's inside
- Hero section with animated jersey and spinning "New Drop" badge
- Scrolling promo band
- Product drop grid (Marilaque, Kennon, Sierra, Bugsuk) with add-to-cart
- Fabric specs
- Custom jersey builder with live preview
- Riders showcase and shop locations

Single static file (`index.html`) — no build step. All jersey graphics are SVG, no external images.

## Deploy
Hosted on Vercel. Every push to `main` redeploys automatically.

## Edit locally
Open `index.html` in any browser.
